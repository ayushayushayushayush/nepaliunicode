How to use the result
  1. Click Copy (or Download .txt), then paste or open it in Word, PowerPoint, Photoshop, etc.
  2. Select the text and set the font to Preeti.

Preeti text looks like gibberish (e.g. g]kfn) in any normal font. That is expected. The right-hand box only shows real Nepali if the Preeti font is installed on your computer, or if you switch the preview to Kantipur font, which this page loads itself. The switch changes only how the preview looks; the copied and downloaded text is the same either way. Keep downloaded files as UTF-8.

Conversion rules based on the converter at ashesh.com.np/unicode-preeti, with extra fixes for half letters, word-final halant, reph placement, chandrabindu and several conjuncts.
