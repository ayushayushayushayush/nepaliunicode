Sync settings (GitHub)
Do this once on each device:
  1. On GitHub open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Under "Repository access" choose Only select repositories and pick just this repo.
  3. Under "Permissions → Repository permissions" set Contents to Read and write. Nothing else is needed.
  4. Paste the token above and press Save & connect. The words are stored in the file named above (it is created on the first added word).
Devices without a token can still read the shared words but cannot add new ones to the repo.
